# Two big buttons on The Tampa Scoop site (about 3 minutes)

**Goal:** make "Events Calendar" and "Local Directory" big and easy to spot when someone opens tampascoop.beehiiv.com.

## First, the honest answer

- **The free basic builder can't add buttons to the homepage.** The homepage has a fixed layout: logo, headline, description, email box and "Subscribe free" button, then your posts. You can change the text, but there is no "add block" or "add button" option. Custom buttons and sections come with the Advanced builder, which you have to pay to publish. Don't use it.
- **Your two links are already in the menu bar** at the top of every page, and they open in a new tab.

So the best free way to get **big teal buttons** is a short **"Start here" post** that you feature at the top of the homepage. Post buttons are already teal: the email style I set up uses teal #0F5C6E with white text.

## Step 1: Make a "Start here" post with two teal buttons (about 2 minutes)

1. In beehiiv, click **Start writing** (or **Posts → New post**).
2. **Title:** `Start here: Tampa events & local spots`
3. **Subtitle:** `Everything The Tampa Scoop has, in one place.`
4. In the body, type `/` and choose **Button**. Set:
   - Text: `📅 Events Calendar`
   - Link (URL): `https://tampa-events.pages.dev`
5. Press Enter, type `/` again, choose **Button** and set:
   - Text: `📍 Local Directory`
   - Link (URL): `https://tampa-directory.pages.dev`
6. Click a button to check its settings. If you see a size or width option, pick **Large** or **Full width**. The color should already be teal (#0F5C6E). If it isn't, set the button color to `#0F5C6E` and the text color to white.
7. **Optional:** below the buttons, add one line such as "New issues land in your inbox every week, so subscribe above."

## Step 2: Publish it to the website only, not by email (about 1 minute)

1. Click **Continue** (or **Next** / **Publish settings**).
2. **Audience:** choose **Web only** (or **Publish to web**). Make sure **Email is OFF**, or this post goes to your subscribers.
3. Turn on **Feature this post** (or **Featured** / **Pin to top**) if you see it. It puts the post at the top of the homepage.
4. Click **Publish now**. Don't schedule it.

## Step 3: Point the homepage text at the buttons (optional, 30 seconds)

1. Go to **Website** → **Edit design** → **Pages** → **Home**.
2. Click the description under the headline and add at the end: `New here? Start with the Events Calendar and Local Directory below.`
3. If you can highlight words there and a 🔗 link icon appears, link "Events Calendar" and "Local Directory" to the two addresses above. If there's no link icon, plain text is fine.
4. Click **Publish changes**.

## Subscribe page

You can't add buttons or links here. Its only settings are the heading, the text, the email box and the background. The menu links at the top are the way from there to the calendar and directory.

## Footer

- Open **Website** → **Edit design** → **Globals** (or **Footer** / **Navigation**).
- If you see **Footer links** (or **Add link**), add **Events Calendar** and **Local Directory** with the two addresses above, then click **Publish changes**.
- In my last visit the footer only showed "© 2026 The Tampa Scoop." with no link option. If that's still the case, skip it. Your menu links and the "Start here" buttons cover it.

## Avoid (costs money)

- **Advanced website builder:** it needs a paid plan to publish.
- **Upgrade buttons:** don't click any of them.
